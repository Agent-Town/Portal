# Agent Town Global Icons

Reusable presentation icons for Agent Town UI surfaces.

Rules:
- These icons are visual assets only. They do not define resources, costs, timers, tools, permissions, or gameplay truth.
- Server code should reference icons through `server/agent_town_icons.js`.
- Browser code should reference icons through `/agent-town-icons.js`.
- Generated Universe packs may reskin these ids later, but canonical mechanics remain server-owned.

Current asset set: `agent-town-global-icons-v1`.
