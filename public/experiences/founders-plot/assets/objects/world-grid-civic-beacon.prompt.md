# World Grid Civic Beacon v1 Prompt

Use case: stylized-concept
Asset type: production 2D game object prop for AgentTown Founders Plot; square PNG source image for chroma-key alpha removal.

Primary request: Create a single cozy World Grid civic beacon prop for a frontier-tech city-builder. It is a harmless read-only civic readiness marker: a small brass-and-wood tabletop/ground beacon with teal ceramic tiles, warm amber indicator glow, a folded blank receipt, and a little ribbon tag with abstract non-readable marks. It must not look like surveillance equipment, a router antenna, weaponry, police/security tech, or a trade-route device.

Visual direction: cozy civic prop, handcrafted frontier-tech, warm brass, soft teal enamel, wood base, neighborly public notice object. Three-quarter isometric object readability. No readable text, no logos, no watermark.

Canvas requirements: square image, object centered with generous padding. Perfectly flat solid #00ff00 chroma-key background outside object silhouette for background removal. The background must be one uniform color with no shadows, gradients, texture, floor plane, reflections, labels, or lighting variation. Do not use #00ff00 anywhere in the object.

Avoid: weapons, drones, cameras, surveillance, route/trade claims, satellite dish, corporate tech, cyberpunk chrome, readable text, UI panels, speech bubbles, logos.
