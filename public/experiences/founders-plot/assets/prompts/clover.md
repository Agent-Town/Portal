# Clover Prompts

## clover-base

Create Clover, the friendly AI Foreman for Agent Town: Founders Plot. Warm, practical, trustworthy frontier guide with a hat, work vest, clipboard or rolled plans, and a readable silhouette at small size. No weapons. No logos. Non-pixel illustrated style.

## clover-states

Use the Clover base and adapt it into these visible states:

- idle
- observing
- thinking
- acting
- waiting approval
- paused
- restart needed

Each state should be visually distinct through pose, prop, or accent marker while remaining consistent with the same character identity.
