# Civic Routekeeper v1 Prompt

Use case: stylized-concept
Asset type: production 2D game character sprite sheet for AgentTown Founders Plot; exact 4 columns x 4 rows, 2048 x 2048 PNG source image for chroma-key alpha removal.

Primary request: Create a dedicated Civic Routekeeper character sprite sheet for a cozy frontier-tech city-builder. Character: Tally-Route 14, a clearly robotic/synthetic civic routekeeper who helps neighbors mark safe civic walking paths and read-only World Grid readiness markers. It has no route authority, no trade mechanics, and no surveillance role.

Visual direction: cozy frontier-tech machinefolk, not cyberpunk. Adult-height compact robot with warm ceramic white panels, brushed brass joints, teal enamel route badges, woven scarf, small ledger satchel, and a friendly expressive cyan face display with two simple eyes, not a camera lens. Holds a rolled paper path ribbon and small wooden wayfinding stake with abstract non-readable marks. Full-body consistent character in every cell. Isometric/three-quarter game sprite readability. No readable text, no logos, no watermark.

Canvas and sheet requirements: EXACTLY 2048 x 2048 square image. EXACTLY 4 columns x 4 rows of equal 512 x 512 animation cells. One full-body character pose per cell, centered with generous padding. Perfectly flat solid #00ff00 chroma-key background outside character silhouettes for background removal. The background must be one uniform color with no shadows, gradients, texture, floor plane, reflections, cell borders, grid lines, labels, or lighting variation. Do not use #00ff00 anywhere in the robot, face display, lights, or props.

Rows, top to bottom:
- Row 1 idle: friendly routekeeper stances with map ribbon and wayfinding stake at rest.
- Row 2 walk: gentle mechanical walking/shuffling while carrying the route ribbon and satchel.
- Row 3 mark: placing a harmless civic wayfinding stake or laying a soft ribbon marker, abstract symbols only.
- Row 4 ready: presenting a small sealed route-readiness token or folded civic path card, reassuring and bounded.

Avoid: weapons, combat robot, drone, surveillance camera, single camera-eye face, faceless automation, police/military, cyberpunk chrome, black tactical materials, harsh red lights, humanoid android skin, readable text, UI panels, route/trade claims, speech bubbles, logos, childlike toy mascot proportions.
