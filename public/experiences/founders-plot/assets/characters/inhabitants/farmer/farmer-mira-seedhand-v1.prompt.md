# Farmer Mira Seedhand v1 Prompt

Use case: stylized-concept

Asset type: production candidate 2D game character sprite sheet for AgentTown Founders Plot, exact 4 columns x 4 rows, 2048 x 2048 PNG source image for chroma-key alpha removal.

Primary request: create a dedicated Farm Plot operator and grower sprite sheet for AgentTown Founders Plot. Character: Mira Seedhand, an adult-coded cozy frontier-tech grower. She makes the existing food loop feel tended, local, and recurring without implying any yield buff or hidden mechanic.

Visual direction: warm earth greens and straw yellows, linen apron, rolled sleeves, seed satchel, small watering can, crop marker sticks, practical boots, and a tiny cyan soil-sensor bead. Friendly focused posture, readable storybook town-builder silhouette, consistent scale across all frames.

Canvas and sheet requirements: exactly 2048 x 2048 square image. Exactly 4 columns x 4 rows of equal 512 x 512 animation cells. One centered full-body character pose per cell. Flat solid #ff00ff magenta chroma-key background behind the character, no shadows outside the character, no transparent checkerboard, no readable text, no logos, no watermark.

Animation rows:

- Row 1 idle/check: checking a seed tray, soil marker, or nearby crop row.
- Row 2 walk/carry: walking with seed satchel or small watering can.
- Row 3 tend/work: tending a crop row with a subtle cyan soil-sensor glow.
- Row 4 ready/output: holding a gathered food basket and sealed receipt pouch.

Avoid: readable text, logos, fantasy magic, weapons, combat poses, cyberpunk styling, child mascot proportions, drone/surveillance cues, hidden gameplay authority, and any pose or prop crossing into neighboring cells.

Boundary: this asset is a visual-only Farm Plot operator candidate. It does not change resource math, production timing, rewards, scheduler behavior, route/trade behavior, Atlas execution, or public effects.
