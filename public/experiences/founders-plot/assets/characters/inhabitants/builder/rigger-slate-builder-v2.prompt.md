# Rigger Slate Builder v2 Prompt

Use case: stylized-concept
Asset type: Founders Plot 4x4 sprite sheet for the builder visual actor.

Create a 4x4 sprite sheet for Rigger Slate, an adult-coded AI construction agent for Agent Town's Founders Plot.

Rigger is not a human settler and must not look like Clover. He is a compact frontier machinefolk field-builder: a sturdy brass-and-teal survey robot with a warm cyan lens/display face, boxy instrument head, small antenna beacon, jointed mechanical arms with padded tool hands, canvas tool straps, worn brass panels, teal enamel shoulder/leg plates, weighted boots, and a practical construction harness. He should feel like an AI site foreman attracted to the frontier between human settlers and future autonomous agents.

Style constraints:
- Match the painterly, chunky, friendly Founders Plot/Clover sprite style.
- Adult-coded, competent, frontier worker energy.
- Cute enough to be approachable, but not childlike, plush, mascot-like, or Clover-shaped.
- No human beard, scarf, hair, skin face, ordinary shirt, or normal human head.
- No hard chrome sci-fi soldier, weapon, villain, skeleton, or combat armor.
- Keep a readable silhouette at small in-game size.

Sprite sheet:
- 2048x2048 square source if possible.
- 4 columns x 4 rows, 16 frames total.
- Row 1: idle/standby, calm construction-agent poses.
- Row 2: build/work, measuring, bracing, tightening, surveying, or marking wood.
- Row 3: inspect/compute, plans, tripod sighting, sensor readout, calculation gestures.
- Row 4: complete/ready, thumbs-up, beacon, folded tools, confident ready pose.

Background:
- Perfectly flat solid #ff00ff chroma-key background for alpha removal.
- No shadows, gradients, floor plane, texture, text, labels, watermarks, or border.
- Do not use #ff00ff in the character.

Reference intent:
- Use the no-hole Clover v1_4_4 sheets only for polish, scale, and painterly finish.
- Do not copy Clover's body, face, costume, or silhouette.
