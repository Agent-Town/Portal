# Lumber Worker Jun Timberline v1 Prompt

Use case: stylized-concept

Asset type: production candidate 2D game character sprite sheet for AgentTown Founders Plot, exact 4 columns x 4 rows, 2048 x 2048 PNG source image for chroma-key alpha removal.

Primary request: create a dedicated Lumber Camp operator and wood steward sprite sheet for AgentTown Founders Plot. Character: Jun Timberline, an adult-coded androgynous/nonbinary-coded lumber worker and wood steward. Jun makes the existing wood loop feel careful, local, and receipt-bound without implying any production bonus or hidden mechanic.

Visual direction: warm multicultural human character, visibly distinct from Mira Seedhand and Bram Stonecalm. Androgynous/nonbinary-coded presentation, practical work gloves, plank gauge, bundle straps, safe hand saw stored on belt, cedar/ochre palette, cyan grain-reader charm, sturdy but friendly posture, clean town-builder silhouette. The design should read as stewardship and repair culture, not extraction.

Canvas and sheet requirements: exactly 2048 x 2048 square image. Exactly 4 columns x 4 rows of equal 512 x 512 animation cells. One centered full-body character pose per cell. Flat solid #ff00ff magenta chroma-key background behind the character in every cell, no shadows outside the character, no transparent checkerboard, no readable text, no logos, no watermark. Consistent scale and silhouette across all 16 frames. Keep all props and limbs inside each 512px cell.

Animation rows:

- Row 1 idle/check: checking stacked planks, a plank gauge, or a camp marker.
- Row 2 walk/carry: walking with a tied board bundle or bundle straps.
- Row 3 mill/work: measuring, sanding, or sorting planks with a subtle cyan grain-reader cue.
- Row 4 ready/output: presenting bundled wood and a sealed receipt pouch.

Avoid: readable text, logos, fantasy magic, violent axe swings, combat poses, deforestation framing, rugged male-default lumberjack caricature, national-costume shorthand, stereotypes, child mascot proportions, drone or surveillance cues, hidden gameplay authority, and any pose or prop crossing into neighboring cells.

Boundary: this asset is a visual-only Lumber Camp operator candidate. It does not change resource math, production timing, rewards, scheduler behavior, route/trade behavior, Atlas execution, public effects, or server authority.
