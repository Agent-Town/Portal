# Oracle Adjunct v1 Prompt

Use case: stylized-concept
Asset type: production 2D game character sprite sheet for AgentTown Founders Plot; exact 4 columns x 4 rows, 2048 x 2048 PNG source image for chroma-key alpha removal.

Primary request: Create a dedicated Oracle Adjunct character sprite sheet for a cozy frontier-tech city-builder. Character: Pella-Node, a visibly synthetic/agentic civic oracle adjunct who helps neighbors interpret read-only civic signals and World Grid readiness receipts. It is a bounded assistant, not an all-seeing oracle and not surveillance.

Visual direction: cozy frontier-tech construct, not cyberpunk. Adult-height slim synthetic clerk with porcelain faceplate showing simple warm amber eyes, small halo-like brass signal ring behind head, teal wool shoulder wrap, little bellows-powered note printer at the belt with blank abstract slips, articulated hands, luminous but friendly chest glyph with abstract non-readable pattern. More civic librarian/assistant than mystical machine. Full-body consistent character in every cell. Isometric/three-quarter game sprite readability. No readable text, no logos, no watermark.

Canvas and sheet requirements: EXACTLY 2048 x 2048 square image. EXACTLY 4 columns x 4 rows of equal 512 x 512 animation cells. One full-body character pose per cell, centered with generous padding. Perfectly flat solid #00ff00 chroma-key background outside character silhouettes for background removal. The background must be one uniform color with no shadows, gradients, texture, floor plane, reflections, cell borders, grid lines, labels, or lighting variation. Do not use #00ff00 anywhere in the synthetic character, lights, wrap, or props.

Rows, top to bottom:
- Row 1 idle: calm adjunct stances holding blank receipt slips and a small civic signal charm.
- Row 2 walk: measured walking with cloak/wrap movement, note printer and slips secured.
- Row 3 consult: reading a small non-readable signal tile, comparing two blank civic slips, careful and helpful.
- Row 4 ready: presenting a sealed readiness receipt or warm signal token, explicitly bounded and neighborly.

Avoid: weapons, combat robot, drone, surveillance camera, camera lens face, faceless automation, police/military, ominous oracle, cyberpunk chrome, black tactical materials, harsh red lights, humanoid android skin, readable text, UI panels, speech bubbles, logos, public-effect claims, childlike toy mascot proportions.
