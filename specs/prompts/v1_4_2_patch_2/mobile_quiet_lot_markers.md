# GPT Image 2 Prompt — Mobile Quiet Lot Markers

## Purpose

Generate small quiet in-world markers for non-objective buildable and locked lots on mobile. These should replace noisy text labels like repeated `Build here` chips.

## Prompt

Small frontier settlement lot markers for a warm storybook town-builder game. Create a compact set of quiet marker objects: wooden stake with ribbon, small survey flag, subtle lock marker on a post, gentle recommended-objective marker with warm glow, selected-lot marker frame. Soft 3D storybook style, warm frontier materials, readable at tiny mobile size, no text, no logos, no UI words, no cyberpunk, no pixel art, transparent/clean background for game integration.

## Required variants

1. quiet available lot marker;
2. locked lot marker;
3. objective/recommended lot marker;
4. selected lot marker;
5. critical warning marker.

## Notes

- The quiet available marker must not pull attention away from the objective.
- The objective marker may be brighter but must not feel like a generic mobile ad badge.
- These may also be implemented as CSS/SVG if generation is unnecessary.
