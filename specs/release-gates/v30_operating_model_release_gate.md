# V3.0 Operating Model Release Gate

Status: required before promoting `FEATURE_FOUNDERS_V30_OPERATING_MODEL`.

## Product Gate

- Charter choice feels like an operating style, not a large science tree.
- Capability Web changes meaningful actions or contract weighting.
- Player can understand the tradeoff before choosing.

## QA Gate

- Charter changes deterministic contract deck weights.
- Capability unlock changes allowed tools/actions only after criteria pass.
- Recap and Three.js state coverage show the selected charter.
- 390px and 1280px screenshots show readable banners/signage.

## Security Gate

- Charter/capability state cannot grant unauthorized Foreman permissions.
- Public exports redact Brain, wallet, debug, and private event data.

## Migration And Rollback

- Older towns receive no selected charter by default.
- Feature flag default is off.
- Rollback hides operating drawer/cards without corrupting contract history.
