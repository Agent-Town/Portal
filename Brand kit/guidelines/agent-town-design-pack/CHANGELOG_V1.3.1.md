## Main rule changes

- Full player route must not show Agent Comms / worker-debug console in normal gameplay.
- Primary-view assets require named human approval metadata.
- Canonical hero frame is required for final visual signoff.
- Clover `ACTING` must be target-linked.
- Mobile labels must be suppressed by default.
- Only one objective-relevant object may receive strong attention by default.
- OpenRouter/proxy work must be split or quarantined.

## Intent

Preserve the structural wins of V1.3 while finishing art quality, embodiment, mobile hierarchy, goal clarity, and release hygiene.
