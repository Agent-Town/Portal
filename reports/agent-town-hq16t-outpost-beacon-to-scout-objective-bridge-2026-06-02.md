# HQ16T Outpost Beacon to Scout Objective Bridge

## Verdict

`PASS`.

HQ16T adds a tiny read-only bridge from the selected `outpost_crew` status surface to the existing Scout objective path. The bridge keeps the outpost origin anchored to the server-owned outpost unit cell, exposes the same server-hinted `frontier_hint` target as read-only UI metadata, and proves that the outpost beacon target, Scout objective marker, selected hinted cell, and existing Scout Sector affordance all point to the same cell.

  - `data-bridge-command-id="scout_sector"`
  - `data-bridge-read-only="true"`
  - `data-bridge-actions="0"`
- Extended the focused outpost map browser proof to verify:
  - outpost beacon target equals the Scout objective marker target
  - existing objective-marker selection focuses the hinted frontier cell

  - no outpost commands, renderer authority, movement authority, reveal authority, route authority, Atlas execution, or external effects are introduced
