# Phase D3 Evidence

Status: Captured on 2026-03-16

This folder contains the before and after screenshots for the D3 implementation:

1. House modal at desktop and mobile
2. Town Hall modal at desktop and mobile
3. Town Board as the simple-room consistency proof

## Comparison notes

### Shared shell

Before:

1. the wood header and border were louder than the room content,
2. the modal body felt like a container inside another container inside another container,
3. every inner panel looked almost equally important.

After:

1. the shell reads as a quiet frame instead of the primary visual event,
2. spacing now belongs to the body, not repeated heavy panel borders,
3. the close control stays obvious without dominating the room.

Why the hierarchy is better:

1. the user lands on the room itself, not on decorative shell chrome,
2. each room now feels like part of one product rather than a separate mini-site,
3. the shell remains stable enough for multilingual labels and future voice references.

### House

Before:

1. the lead gate panel and the follow-up panels all carried roughly the same border and shadow weight,
2. the shell competed with the steps,
3. the room felt mechanically segmented.

After:

1. the lead gate panel reads first,
2. the shell recedes and the steps become easier to scan in sequence,
3. the room feels calmer without changing any logic.

### Town Hall

Before:

1. the onboarding card sat inside a loud shell with a large amount of empty stage around it,
2. the modal frame did not help the user understand where to focus,
3. the room felt more administrative than ceremonial.

After:

1. the onboarding content is centered as the lead surface,
2. the shell provides support instead of spectacle,
3. the first screenful is more obviously about the current decision.

### Town Board

Before:

1. a very simple room inherited the same large proportions as more complex rooms,
2. the result was a lot of empty parchment below one small content card.

After:

1. the room uses a tighter envelope,
2. the content feels proportional to the task,
3. the room no longer feels like a nearly empty large modal.
