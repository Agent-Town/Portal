# Agent Town V1.4.3 — App-Wide GPT Image 2 Prompt Library

This is the shared prompt library for non-game app assets.

Production prompts must be stored as separate files under:

```text

```

## Global positive style

Warm frontier storybook / soft 3D collectible game art for Agent Town. Cozy but not childish. Frontier civic-builder mood. Tactile wood, brass, parchment, leather, clay, canvas, and warm glass. Golden-hour light, rounded silhouettes, strong readable shapes, friendly optimism, slight humor. Coherent with Founders Plot V1.4.2 art. No embedded text unless explicitly requested.

## Global negative style

No cyberpunk, no neon sci-fi, no grimdark realism, no generic SaaS dashboard, no pixel art, no flat placeholder vector style, no fake mobile ad clutter, no illegible tiny details, no fake text, no exact imitation of commercial game UI, no modern glassmorphism as the primary style, no horror, no militarized western violence.
